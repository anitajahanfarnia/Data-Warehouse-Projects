Chinook Data Warehouse

Designed and implemented a data warehouse based on the Chinook database using SQL Server Integration Services (SSIS).

The Chinook database tables were analyzed to determine which tables and columns were more suitable for Dimension and Fact tables. The required transformations and ETL process were then implemented using SSIS, and the transformed data was loaded into a data warehouse in SQL Server.

Finally, the relationships between the tables were created in SQL Server Management Studio (SSMS), connecting the Dimension tables to the Fact table.

The Chinook database represents a digital music store and contains data related to artists, albums, tracks, customers, employees, invoices, and sales transactions.

Tools: SQL Server | SSIS | SSMS | ETL
